# **IOT2050**

## **Device Variants (PGx) and Functional States (FS)**

Please refer to https://support.industry.siemens.com/forum/de/en/posts/overview-about-fs-states-of-iot2050/273280/?page=0&pageSize=10.

- PG1:
  - Basic: FS:01
  - Advanced: FS:01, FS:02, FS:03
- PG2:
  - Basic: FS:02, FS:03
  - Advanced: FS:04, FS:05

## **List of tested devices:**

The following tables show the out-of-the-box support of different extensions modules for the IOT2050.

- [Support of mPCIe cards](#support-of-mcpie)

The chance is high that devices which are working on PG1 and marked as "not tested" for PG2, are also working on PG2.

**ℹ️ Note**:
*Recent Quectel firmware/hardware changes have created incompatibilities with ModemManager, causing previously supported Quectel cards to no longer work properly with IOT2050 when using the default ModemManager. For optimal compatibility, consider using QConnect Manager or verify specific firmware versions compatible with ModemManager before deployment. Quectel recommends using their proprietary QConnect Manager instead of ModemManager for their cellular modules. Consult Quectel's documentation for detailed compatibility information.*
